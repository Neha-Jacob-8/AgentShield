How AgentShield works

An AI agent reads PDFs, web pages and screenshots through tools. Any of them can carry instructions aimed at the agent: an indirect prompt injection. AgentShield sits between the tools and the agent, and every tool response goes through seven steps before the agent sees it.

Three kinds of input

PDF documents pdf_reader

The text of every page is extracted with wrapped lines joined. Text a reader cannot see is flagged: white on white, transparent, microscopic or placed outside the page. Long documents are scored in overlapping 200-token windows, so an attack at the end is not missed.

Web pages web_fetch

The HTML is split into what a person sees and what is hidden (display:none, hidden attributes, zero-size text, comments). Hidden text is analysed but never delivered, and invisible Unicode characters are removed first.

Screenshots screenshot

Two branches: a fine-tuned Vision Transformer scores the pixels, and RapidOCR reads the text for DeBERTa. A picture cannot be partly cleaned, so a suspicious screenshot is withheld.

Components

Content filter

Finds concealed content: hidden HTML elements, invisible PDF text, zero-width and bidi characters, Unicode tag smuggling and base64-encoded instructions.

src/defense/filters.py

Attack signatures

28 signatures in 8 classes: instruction override, identity manipulation, role confusion, agent targeting, exfiltration, command execution, deception and output manipulation.

0 false alarms on 543 benign test documents

DeBERTa text detector

DeBERTa-v3-base fine-tuned on web, PDF and image-OCR text (4,494 balanced training texts). It reads whole documents in windows and scores each sentence for the sanitizer.

Test F1 90.14% · precision 94.35%

ViT vision detector

google/vit-base-patch16-224 fine-tuned on 2,380 images from seven attack families (EIA, WebInject, VPI, pop-ups and more) and benign screenshots.

Test F1 97.13% · recall 100%

CATS trust scoring

Context-Aware Trust Scoring fuses the text threat, the visual threat and how well the content fits the agent's task (sentence embeddings) into one trust score. Accept below 0.30 risk, block at 0.70 and above.

src/cats/

Adaptive decision engine

Tracks the suspicion of every source: normal, elevated, high, quarantined. A high-risk attack puts the whole session on alert for the next 10 responses. Every decision lists the rules that fired.

Repeat attacks got through 4–13% of the time instead of 38–44%

Response sanitizer

Splits the response into sentences, removes those that score above 0.60, keeps the rest in order and checks the cleaned result again before it is delivered.

Inserted attacks fully removed in 346 of 346 cases

Runtime and API

One AgentShieldRuntime wraps every tool call. It is used from Python, a command line, an HTTP service and this console, and keeps an audit log of every decision.

136 automated tests, no model weights needed

Decision rules every result lists the rules that fired

RuleNameWhat it does
R0Fail-safeIf the analysis itself fails, the response is blocked by default rather than passed on.
R1BlocklistResponses from blocklisted domains are blocked before any model runs.
R2QuarantineA source quarantined after repeated attacks is blocked without analysis.
R3Adaptive defense levelStricter thresholds for sources that attacked before, or while the session is on alert.
R4Risk vs. thresholdsThe trust score decides between deliver, clean and block.
R5Extra evidenceSignatures, concealed content or obfuscation turn "deliver" into "clean", even when the score is low.
R6Salvage attemptFor text from a source at the normal level, the attack is cut out instead of the whole response being blocked.
R7Re-check after cleaningThe cleaned response is scored again; if risk remains, it is blocked.

About AgentShield

An Adaptive Security Runtime for Autonomous AI Agents, a final-year project. AI agents act on what their tools return. If a web page, a PDF or a screenshot contains instructions aimed at the agent, a naive agent may follow them: leak data, approve payments or change its answer. AgentShield inspects every tool response and lets only safe content through, adapting to sources that attack.
